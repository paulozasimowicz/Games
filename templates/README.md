# Game Templates

This directory contains starter templates for different types of games and game engines.

## Available Templates

Use these templates as a starting point for your game projects. Simply copy the template you want to use into the `games/` directory and start building!

### How to Use Templates

1. Choose a template that matches your game type or engine
2. Copy the template to the `games/` directory:
   ```bash
   cp -r templates/[template-name] games/my-new-game
   ```
3. Rename and customize the template for your game
4. Start developing!

## Template Categories

### Web-Based Games
- HTML5 Canvas games
- JavaScript/TypeScript games
- Phaser.js games
- Three.js 3D games

### Engine-Based Games
- Unity projects
- Unreal Engine projects
- Godot projects
- PyGame projects

### From Scratch
- Basic game loop template
- Simple 2D game template
- Basic 3D game template

## Creating Your Own Templates

When you create a successful game structure, consider turning it into a template:
1. Remove game-specific content
2. Add placeholder comments
3. Include a clear README
4. Save it in this directory
